## 1. 这个节点是干什么的

- **一句话**：把 Excel 第 4 列（`分类路径`）按 `/` 拆成 5 段，依次选进发布页的 5 个独立下拉框：**分类 / 品牌 / 成色 / 长度 / 材质**。
- **没它会怎样**：类目错放，平台可能限流/下架；买家搜不到；后续改价/改描述也失去参照。
- **它不负责**：不生成分类路径、不纠正段序、不判断平台类目语义（预检只能查格式，查不了顺序）。
- **边界**：任一目标值点不到 → 本行判失败并跳过，**绝不带着错分类发布**。

## 2. 总流程

```text
选择分类（画布 037 调用 {row: list(loop_excel)}）
  │
  ├─ 读 Excel 索引 3（分类路径）→ 按 "/" 拆分、去空白
  │   ├─ 空路径 → RuntimeError → ok=false
  │   └─ 段数 > 5 → 多余段忽略并告警
  │
  ├─ 每个字段（最多 2 轮）：
  │   ├─ 按 label 找 ant-form-item
  │   │   └─ 已选中目标值（包含）→ 幂等跳过
  │   ├─ 点开 .ant-select
  │   ├─ 在搜索框键入目标值（过滤长列表）
  │   ├─ 轮询 5s 找「包含目标值」且可见的选项 → 点击
  │   ├─ 重新取字段复核；未生效 → Esc → 重试
  │   └─ 2 轮仍不中 → 本字段失败
  │
  ├─ 五字段串行：任一字段失败 → 立即返回 False
  │
  └─ 返回 {"ok": true/false, "step": 4}
        └─ 画布 038–041：写「上架失败」→ 保存 → 继续下一行
```

## 3. 动作细节

### 3.1 路径拆分与五字段串行

```text
path = [p.strip() for p in str(cell(row, 3)).split("/") if p.strip()]
├─ 空 → RuntimeError("分类路径为空")
├─ len(path) > 5 → 告警，保留前 5 段
└─ for label, target in zip(FIELDS, path):
     ├─ 选中 → 记录「label = target」，继续
     └─ 失败 → 记录日志「字段 X 没选中 Y，该行判失败」→ 立即 return False
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 分类路径 | Excel 0 基索引 3（第 4 列） | 空即失败 |
| 分隔符 | `/`（**全角 `／` 不拆**，预检 `CAT_FULLWIDTH` 拦） | — |
| 字段顺序 | `["分类","品牌","成色","长度","材质"]` | 常量 `FIELDS` |
| 多余段 | 超过 5 段 | 忽略并告警 |
| 不足段 | 少于 5 段 | 只填前 N 个，**仍返回 True** |

**判断标准**：路径中每个出现的段都选中 = 成功；任一段点不中/路径为空/字段不存在 = 失败。

> **「成功」不等于「五个字段都填了」**：路径只有 3 段时只校验 3 个字段。这是宽松口径，靠预检 `CAT_DEPTH`（warn）提示层数异常。

### 3.2 字段定位与幂等

```text
_form_item(page, label)
├─ 遍历 css:.ant-form-item
│   ├─ 每个表单项取 tag:label（0.3s）
│   ├─ label.attr("title") 或 label.text 去空白
│   └─ == 字段名 → 返回该表单项
└─ 全部不匹配 → None

幂等：target in item.text ？
├─ 是 → 直接成功，不点下拉
└─ 否 → 进入 3.3
```

| 结论 | 判据 |
|------|------|
| 字段存在 | label 名 == 字段名的表单项 |
| 已正确 | 表单项文本包含目标值 |
| 需要操作 | 字段存在但当前值不含目标值 |

> 用「字段名」定位而不是下标：页面字段顺序会变，名字是语义。

### 3.3 下拉选择

```text
_select_field(page, label, target)
└─ 最多 2 轮：
   ├─ _form_item → None → 失败；已含 target → 成功
   ├─ .ant-select 找不到 → 失败
   ├─ 点开下拉 → 0.5s
   ├─ 找搜索框 input（1s）→ 有则键入 target（失败不致命）
   ├─ _click_option(target, 5s)
   │   ├─ 轮询 .ant-select-item-option / [class*=option]
   │   ├─ 文本包含 target 且可见 → 点击 → True
   │   └─ 超时 → False
   ├─ 点中后 0.5s → 重新取字段复核
   │   ├─ 新字段文本含 target → 成功
   │   └─ 不含 → 记日志，重试
   └─ Esc 关闭 → 0.3s
```

| 结论 | 判据 |
|------|------|
| 选中成功 | 点击后重新取到的字段文本包含目标值 |
| 点击未生效 | 选项点了，但字段文本仍不含目标值 |
| 找不到选项 | 5s 内没有「包含目标值且可见」的选项 |

**失败怎么办**：

| 现象 | 判据 | 处理 |
|------|------|------|
| 字段不是下拉 | `.ant-select` 缺失 | 本字段失败 |
| 选项异步没出来 | 5s 轮询空 | 重试一轮；仍空 → 失败 |
| 点击后页面重建 | 旧句柄失效 | 重新 `_form_item()` 复核 |
| 目标值根本不存在 | 两轮都点不中 | 整行失败，**不猜近似值** |

> 为什么不用固定 `sleep`：过滤/重建是异步的，固定等待会撞空列表（失败模式 D6）。
> 为什么用「包含」而不是相等：页面选项带前缀/区间（`安踏`→`ANTA/安踏`、`189`→`180-189cm`）。

## 4. 对外契约

| 项 | 现状 |
|----|------|
| 返回值 | `{"ok": bool, "step": 4}`；失败不带 `error`（异常路径才带） |
| 输入列 | 0 基索引 3（第 4 列 `分类路径`） |
| 字段顺序 | 固定 `分类 → 品牌 → 成色 → 长度 → 材质` |
| 匹配方式 | 页面选项文本**包含**目标值 |
| 段数 < 5 | 只填前 N 段，仍返回 True（预检 `CAT_DEPTH` warn 兜底） |
| 段序错 | 本层发现不了，也兜不住 |

**页面结构改版**：

**真实故障 · 段序错位（2026-11-07 10:26）**：

- 现象：P002 卡死，每轮 21–25 秒。
- 根因：页面第 4 框是「连接方式」，Excel 写的是「全新」→ 选项永远匹配不到 → 重试。
- 处置：数据重排 + 两道守卫，把「段序错」安全降级为「判失败跳过」，不再死循环。
- 结论：**段序对不对，离线预检判断不了**——只有页面知道每级候选值；`全新` 在 `发饰/DIY/全新/抓夹` 里就是正常分类节点（`docs/优化路线图.md` §Q1）。
