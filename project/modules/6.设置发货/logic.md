## 1. 这个节点是干什么的

- **一句话**：按 Excel 第 9 列（`发货设置`）的文字，选中四选一的发货方式，必要时追加「支持自提」。
- **没它会怎样**：运费口径错——该包邮的收了运费，或该到付的写成包邮，直接影响成交与纠纷。
- **它不负责**：不计算运费、不判断地址/自提点、不校验文案合法性。
- **边界**：只认四个关键词 + 「支持自提」；不在关键词里的文字**静默走「无需邮寄」**。

## 3. 动作细节

### 3.1 四分支选择

```text
ship = str(cell(row, 8))
├─ "包邮" in ship       → click(包邮按钮)
├─ "按距离计费" in ship → click(按距离计费)
├─ "一口价" in ship     → click(一口价)
└─ 以上都不含（含空值/错字）→ click(无需邮寄)
└─ 等 1s
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `ship` | Excel 0 基索引 8（第 9 列） | 空串合法（落 else） |
| 关键词顺序 | 包邮 → 按距离计费 → 一口价 | `if/elif` 固定 |
| 页面元素 | `包邮按钮` / `按距离计费` / `一口价` / `无需邮寄` | 长 XPath → `text=...` |

**判断标准**：对应文本的元素点击不抛错 = 成功；文本不在三个关键词里 = 静默点「无需邮寄」，**不报错**；元素找不到/点击抛错 = 失败。

**失败怎么办**：

| 现象 | 判据 | 后果 |
|------|------|------|
| 文本为空/错字 | 三个关键词都不含 | 静默走「无需邮寄」——**需预检/人工兜底** |
| 文案同时含多个关键词 | 例：`包邮，支持自提` | 顺序决定结果：先命中包邮 |
| 元素找不到 | 候选落空 | 本行「上架失败」 |
| 点击被遮挡 | 点击抛错 | 同上 |

> **不要给 else 加「报错」**：当前口径是「发货空 → 无需邮寄」；改成失败会改变历史数据处理口径，需先确认。

### 3.2 支持自提

```text
四分支点完 → 等 1s
├─ "支持自提" in ship → click(支持自提) → 等 1s
└─ 否则 → 不做任何事
```

| 结论 | 判据 |
|------|------|
| 已追加 | 点击不抛错 |
| 不需要 | 文本不含「支持自提」 |
| 失败 | 文本含但元素找不到/点击抛错 → 整行失败 |

> 分支顺序是语义的一部分：`包邮 支持自提` 会先命中包邮，再追加自提。
