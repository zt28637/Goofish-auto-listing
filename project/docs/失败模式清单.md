# 失败模式清单 — 自动化上架全景

> 用途：把「能跑通」推进到「知道它在什么条件下会坏」。
> 覆盖本仓真实存在的洞 + 外部自动化上架常见、本仓尚未遇到但必须能回答的问题。
> 更新口径：每条按 **触发条件 → 代价 → 检测 → 应对** 写；状态变化时改标记，不删条目。

## 图例

| 标记 | 含义 |
|---|---|
| 🔴 | 本仓存在，建议优先处理 |
| 🟡 | 部分覆盖 / 有隐患 / 依赖人工纪律 |
| 🟢 | 已有明确应对 |
| ⚪ | 本仓未出现，但同类项目常见，面试会问 |

> **状态不是罪，未知才是。** ⚪ 不等于要立刻实现，等于你要能说出「为什么现在不做、什么时候做」。

## B. 输入契约与数据

| 编号 | 问题（触发 → 代价） | 本仓 | 检测 / 应对 |

| B4 | 分类路径空段（`服饰//抓夹`）→ 级联点击必挂 | 🟢 | `CAT_EMPTYSEG`；但**全角斜杠 `／`** 不拆分，需归一化 |

| B6 | 图片格式/尺寸/大小超平台限制（webp、heic、超大图） | 🟡 | 上传前预检：扩展名白名单 + 尺寸上下限 + 单张体积 |
| B7 | 文件名排序 `1, 10, 2` → 主图顺序错 | 🟡 | 字符串排序；上游用 `01_` 两位前缀；或改自然排序 |
| B8 | 空尾行 / 只有格式的幽灵行 | 🟢 | 预检跳过全空行；影刀循环到 `-1` 仍会走到，靠行内容判断 |
| B9 | 商品 ID 重复或缺失 → 回写定位歧义 | ⚪ | 预检加唯一性检查；回写按行号不按 ID，暂不受影响 |

| B11 | Excel 被打开占用 / 只读 / 网盘同步冲突 → 回写失败或覆盖 | ⚪ | 运行前独占打开；网盘目录禁用 |
| B12 | 长路径（>260） / 中文 / 特殊字符路径 | ⚪ | Windows 长路径开关；路径统一走 `Path` |
| B13 | 描述超 1500 字被平台截断 | 🟢 | `DESC_LONG` 预检拦截 |
| B14 | 上游素材没齐就开跑 → 半批失败 | 🟡 | 预检是闸门；但只查四项，原价/发货/地址不在内 |

## L. 面向 Agent 化的预留风险

> 前提：执行层保持确定性，Agent 只出现在「失败归因 / 规则修复 / 语义映射」的位置。
> 一旦让 Agent 直接操作不可逆动作，以下每条都会变成现实问题。

| 编号 | 问题（触发 → 代价） | 本仓 | 检测 / 应对 |
|---|---|---|---|
| L1 | 页面内容是不可信输入（商品描述里藏指令）→ prompt injection | ⚪ | Agent 读到的页面文本视为数据不是指令；工具调用做白名单 |
| L2 | 工具权限过大（能点发布/能改价） | ⚪ | 最小权限：Agent 只能读证据、产出补丁 |
| L3 | 不可逆动作未经确认 | ⚪ | 人工确认闸门；Agent 输出建议而非动作 |
| L4 | Agent 产出的补丁未经验证就生效 | ⚪ | 补丁先在 dry_run 下比对，再合入 |
| L5 | 成本 / 延迟不可控 | ⚪ | 只在异常路径调用；设 token 与超时上限 |
| L6 | 行为不可复现、难审计 | ⚪ | 记录输入证据 + 输出补丁 + 采纳结果，形成审计链 |
| L7 | 模型升级导致行为漂移 | ⚪ | 固定模型版本；关键判断加规则兜底 |

## 怎么用这份清单
