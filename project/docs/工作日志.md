## E01 · 收尾报错，日志从未生成

**事件**：每轮运行结束后抛 `an integer is required (got type str)`，但三项统计正常打印。

**问题**：
- 报错归属「主流程」，是它最后一块「导出日志」
- 根因是把 `datetime` 当字符串做 `.replace(':','-')` → 实际命中 `datetime.replace(year=…)`，传字符串炸
- 更关键：`project/runtime/logs/` **一直是空的**，说明这个错存在很久，只是没人看导出目录

**成果**：
- `main` 块 9 改为 `当前时间.strftime('%Y-%m-%d_%H-%M-%S')+'.txt'`
- 修复后 10:21 起连续 4 份日志正常落盘，直接成为后续排障的证据源
- 记入失败清单 J9；第一版条目写反了（把 bug 当修法），同日在 E07 期间纠正

## E02 · 三项统计全 0

**事件**：跑完显示 `上架成功 0 / 失败 0 / 不明 0`，看起来像全线失败。

**问题**：
- 实际是 N 列全部为「上架成功」，被状态过滤（块 037/038）全部 `continue`
- 这是**设计行为**，不是故障
- 但暴露一个真问题：**预检 PASS ≠ 这轮有活干**，日志里没有任何"跳过 N 行"的提示，看图只会以为坏了

**成果**：
- 确认口径；把 5 行重置为「待上架」重测
- 该现象写进排障经验：先看 N 列再判断"为什么没发"

## E03 · 分类死循环

**事件**：P002 卡在分类级联，日志每 21–25 秒重复一次「目标值=全新」。

**问题**：
- Excel 分类路径段序错位：页面第 4 个框是「连接方式」，Excel 第 4 段写了「全新」
- 选项匹配不到 → 级别不前进 → `While` 无限重试
- **级联没有"匹配不到"的出口**，一行数据错就能卡死整批

**成果**：
- 数据：P002 路径重排为 `智能手表/小天才/Z6/蓝牙连接/35/蓝牙通话/全新`
- 画布：加两道守卫 —— ①级别未推进 ②等待超 10 次 → 写「上架失败」并 `continue` 跳过该行
- 效果：同类错误从"卡死"降级为"安全失败"

## E07 · 预检引入 fail/warn 两级

**事件**：要给输入侧加校验，防止脏数据进到真实发布。

**问题**：
- 最初方案「成色词不该出现在非成色位置」**被真实数据证伪**：`发饰/DIY/全新/抓夹` 里 `全新` 就是正常分类节点
- 单一 fail 级会误伤整批（画布是 `IF 预检["fail"]>0` 全停）
- 朴素关键词会误杀：P002 商品名是「儿童**电话**手表」

**成果**：
- 两级判定：`fail`（一定跑不通，整批停）/ `warn`（可疑但能跑，只提示）；`fail` 语义不变，画布零改动
- 新增 fail：`CAT_FULLWIDTH` `PRICE_ORDER` `PRICE_ORIG_BAD` `IMG_BAD` `DESC_CONTACT`
- 新增 warn：`PRICE_EXTREME` `CAT_DEPTH`（从「上架成功」行**自学习**层数，无样本不判）
- 29 条回归用例；真实数据 `pass=5 warn=0 fail=0` 零误伤
- 记录教训：**分类顺序离线判不了**，只有页面知道每级候选值
