# 闲鱼批量上架自动化

> **影刀 RPA 上架执行引擎**：循环 `商品清单.xlsx`，把套图 + 文案真实上架到闲鱼网页版（goofish.com）。
> 流程 = 影刀 `process3「咸鱼_批量上架」`（**145 块**画布，2026-10-26 11:17 全量转录，已跑通；判定段三路状态列回写）。套图与文案由**上游产出（不在本仓范围）**，本仓只做**预检 + 上架**。
>
> **两段式**：L0 `project/tools/precheck.py`（四项必填校验，`fail>0` 整批中止，引擎无关）→ L1 上架画布。脏数据挡在真实发布之前。

---

## 上架流程（影刀 process3）

```
准备（循环外）：打开发布页（Edge）→ 登录检测/补登（含「快速进入」）→ 路径变量 + 计数器初始化 → 打开 Excel
└ 循环 Excel 行（一行=一件）：
    上架状态判断（读状态列；过滤分支暂空）→ 套图上传 → 描述写入 → 分类级联选择（含 BACKSPACE 清脏值）
    → 价格/原价 → 发货设置 → 发布 → 成败判定（回写状态列 N）→ 跳回发布页（复用同一标签）
收尾：保存关闭 Excel → 打印 成功/失败/不明 三项统计
```

**上游合同**（仅此两条，怎么生成不归本仓管）：
1. `products/<商品ID>/套图/` 里有待上传的图片文件（流程按文件名升序**逐文件全量上传**，不挑扩展名——目录里别放非图片文件）
2. `商品清单.xlsx` 对应行的 分类/价格/原价/发货/套图目录/描述 六列已填好

## 运行要点（实测踩坑固化）

- 发布成败**不靠 toast**（弹窗作废不可判）：判「当前页含咸鱼ID元素」
- 级联/动态元素**先滚动到视口中上部**再操作，否则点不中
- 多选下拉脏值：**循环 `{BACKSPACE}` 清空已选标签再全量重勾**（清输入框无效，残留会串进下一件）
- 成败两路都**跳回发布页**，防脏表单串件
- 流程**循环全部数据行**：跑前确认 Excel 里就是本批要上架的行（「上架状态判断」过滤分支仍为空壳，当前不跳过任何行；重跑会覆盖上轮回写并重复上架）
- 套图目录内出现非图片文件会被一并上传（逐文件不挑扩展名）
